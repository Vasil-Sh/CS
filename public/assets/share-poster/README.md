# MatchIQ share poster assets

`poster-paper.webp` was edited with the built-in imagegen tool from the user's approved reference and encoded as WebP (quality 93) for delivery. It is a blank backdrop only; all match data remains live SVG text and paths. The original PNG is retained in the working artifact folder.

Final prompt: Remove every letter, number, logo, abbreviation, rule, badge and status rectangle. Remove the huge cream numerals and expose the continuous black distressed paper/orange diagonal brush behind them. Keep the original black paper grain, orange corner/diagonal/bottom-left strokes, eroded ivory rail and tilted blank ivory receipt in exactly the same positions. No text, numbers, logos, rules or watermark. Flat 1122 × 1402 reference composition.

`Montserrat.ttf` and `Oswald.ttf` are self-hosted variable fonts from the official google/fonts repository. Their SIL Open Font Licenses are included alongside them. Fonts and backdrop are embedded in exported SVG before PNG rendering so exported typography does not depend on network or operating-system fallback fonts.
