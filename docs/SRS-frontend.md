# SRS — MatchIQ Frontend

> Software Requirements Specification — клієнтська частина платформи MatchIQ.
> Версія документа: 1.0 · Дата: 2026-09-24 · Статус: актуально

---

## 1. Вступ

### 1.1 Призначення

Документ описує функціональні та нефункціональні вимоги до фронтенд-застосунку MatchIQ — веб-платформи для аналітики та трекінгу ставок на CS2 і Dota 2.

### 1.2 Область дії

SPA (Single Page Application), що надає користувачам інтерфейс для ведення ставок, аналітики, управління банкролом, стратегіями, цілями та перегляду матчів з AI-рекомендаціями.

### 1.3 Аудиторія

- Звичайні користувачі (беттери)
- Адміністратори (мають розширені права)

## 3. Функціональні вимоги

### FR-1. Аутентифікація та авторизація

- FR-1.1 Вхід за логіном/паролем (JWT).
- FR-1.2 Демо-режим входу (`/login-digesto-demo`).
- FR-1.3 `ProtectedRoute` блокує незахищені маршрути.
- FR-1.4 Збереження токена в `localStorage`, auto-refresh через `apiClient`.
- FR-1.5 Визначення ролі `admin` (розширені можливості).

### FR-2. Мої ставки (`/app/my-bets`)

- FR-2.1 Створення ординарних та експрес-ставок (авто-розрахунок загального коефіцієнта).
- FR-2.2 Автозаповнення з URL (парсинг HLTV / tips.gg).
- FR-2.3 Мультивалютність: UAH та USD з конвертацією за курсом.
- FR-2.4 Результати ставок: Win / Loss / Pending з обов'язковим коментарем для програшів.
- FR-2.5 Прив'язка ставки до активної цілі (goal).
- FR-2.6 Таблиця записів: пошук, фільтри (today/all, результат, період), сортування, пагінація, видимість колонок.
- FR-2.7 Шеринг ставок: картка `BetShareCard` (стиль квитка з напівкруглими вирізами) зі збереженням як JPEG та копіюванням як зображення (правий клік / кнопка).

### FR-3. Банкрол

- FR-3.1 Початковий банк → поточний банк у реальному часі.
- FR-3.2 Валідація ставок при перевищенні банку.
- FR-3.3 Експорт даних: JSON-бекап (повний) + CSV (ставки).

### FR-4. Аналітика (`/app/analytics`)

- FR-4.1 KPI-картки: банк, профіт, всього ставок, вінрейт, активні, виграші, програші, ROI.
- FR-4.2 Трекер балансу: статус банку, прогрес-бар до максимуму, поради, статистика по CS2/Dota2.
- FR-4.3 Графіки: баланс у часі, місячний профіт (бари), scatter (odds vs profit), odds win rate, bet type donut.
- FR-4.4 Фільтр по грі (CS2/Dota2/all).
- FR-4.5 Календарна теплокарта (12 тижнів).
- FR-4.6 Предиктивна аналітика трендів.

### FR-5. Розумні розрахунки (сайдбар форми)

- FR-5.1 Value Bet — порівняння впевненості з implied probability.
- FR-5.2 EV (Expected Value).
- FR-5.3 Критерій Келлі з кнопкою «Застосувати».
- FR-5.4 Ризик експресу (помірний/підвищений/високий).

### FR-6. Цілі (Goals)

- FR-6.1 Типи: Amount, Ladder, ROI, Win Rate.
- FR-6.2 Прогрес-бари, статуси (активна/завершена/провалена).
- FR-6.3 Автоматичне підтягування суми з останньої ставки.
- FR-6.4 Виділення основної цілі (`isPrimary`).

### FR-7. Стратегії (Strategy)

- FR-7.1 CRUD стратегій з 5 групами правил (OddsControl, BetTypeRules, MatchFormatRules, ActivityLimits, PsychologicalTriggers).
- FR-7.2 Основна стратегія — автоматична перевірка при створенні ставки.
- FR-7.3 Діалог підтвердження при порушенні правил.

### FR-8. Матчі (`/app/matches`)

- FR-8.1 Дані CS2 + Dota2 (cstest API + tips.gg).
- FR-8.2 Перемикач гри (CS2/Dota2/Всі).
- FR-8.3 Картки матчів: логотипи, форми команд, tier, prediction bars.
- FR-8.4 Пошук, фільтри (статус, tier, формат, турнір, впевненість).
- FR-8.5 Multi-select → експрес-ставка.
- FR-8.6 AI-рекомендації на кожен матч.
- FR-8.7 Live auto-refresh (точкове оновлення рахунків).

### FR-9. AI

- FR-9.1 DeepSeek Chat — основний AI для прогнозів.
- FR-9.2 Gemini Flash — fallback.
- FR-9.3 AIRecommendationModal: prediction, confidence, reasoning, risk level.

### FR-10. Ризиковані команди

- FR-10.1 Статуси: БАН / Нестабільні / Обережно / Рідко / Надійна.
- FR-10.2 Google Sheets імпорт.
- FR-10.3 Попередження при виборі risky team у формі.
