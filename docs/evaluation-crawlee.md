# Оцінка: Crawlee vs поточний Puppeteer-скрапер

> Джерело: [`apify/crawlee`](https://github.com/apify/crawlee) (25k ⭐)
> Crawlee — фреймворк для веб-скрапінгу на Node.js, сумісний з Puppeteer і Playwright

---

## Що Crawlee дає з коробки (чого в нас немає)

| Фіча                          | Crawlee                                                 | У нас зараз                |
| ----------------------------- | ------------------------------------------------------- | -------------------------- |
| **Черга URL**                 | Вбудована (BFS/DFS), з пріоритетами                     | Самописний цикл по URL     |
| **Ротація проксі**            | Автоматична, з сесіями                                  | Немає                      |
| **Fingerprint randomization** | Human-like заголовки, TLS fingerprint                   | Голий Puppeteer            |
| **Retry логіка**              | Автоматична, з exponential backoff                      | Самописний circuit breaker |
| **Persistent storage**        | Збереження стану між запусками (Dataset, KeyValueStore) | Filesystem `.cache/`       |
| **Autoscaling**               | Авто-масштабування під доступні ресурси                 | Немає                      |
| **Anti-blocking**             | `RequestQueue` + ротація IP → менше шансів блокування   | Немає                      |
| **Session management**        | Ізоляція кук/сесій між різними джерелами                | Один браузер               |

## Поточний скрапер: анатомія

### `tipsggScraper.ts` (~600 рядків)

Основні компоненти:

- Puppeteer запускає браузер, йде на tips.gg
- Cheerio парсить HTML, витягує JSON-LD + scores
- `circuitBreaker.ts` — 3 помилки → 5 хв пауза
- `coefficientsCache.ts` — кеш коефіцієнтів
- Ротація браузера кожні 15 хв
- Filesystem cache з TTL 5хв fresh / 60хв stale

### Що працює добре

- Circuit breaker стабілізував скрапер після v1.24.11
- JSON-LD парсинг надійний
- Cheerio-екст rackція scores — стабільна

### Що працює погано

- ~600 рядків ручного коду для того, що Crawlee дає з коробки
- Немає ротації IP → Cloudflare може забанити
- Немає persistent queue → при падінні втрачаємо URL
- Браузер іноді крашить → доводиться перезапускати вручну

## Що дасть міграція на Crawlee

### Плюси

| Плюс                 | Деталі                                                                 |
| -------------------- | ---------------------------------------------------------------------- |
| **Менше коду**       | ~600 рядків → ~150 рядків (Crawlee бере на себе чергу, retry, ротацію) |
| **Анти-детект**      | Human-like fingerprint'и + TLS → менше шансів Cloudflare               |
| **Persistent черга** | При падінні скрапера — продовжить з того ж місця                       |
| **Autoscaling**      | Автоматично регулює кількість паралельних запитів                      |
| **Типізація**        | Повна TypeScript підтримка                                             |
| **Сумісність**       | Працює з Puppeteer (той самий браузер)                                 |

### Мінуси

| Мінус               | Деталі                                                                           |
| ------------------- | -------------------------------------------------------------------------------- |
| **Нова залежність** | +1 пакет у `package.json`                                                        |
| **Крива навчання**  | Інша модель: не «відкрити браузер → спарсити», а «визначити crawler → запустити» |
| **Переписування**   | ~1-2 дні роботи на міграцію + тестування                                         |
| **Overkill?**       | Для 1-2 джерел (tips.gg + можливо hltv.org) — Crawlee може бути заважким         |
| **Circuit breaker** | Доведеться адаптувати під Crawlee (або залишити як є)                            |

## Рекомендація

### ❌ НЕ мігрувати зараз

**Причина:** скрапер стабільний після v1.24.11. Circuit breaker працює. Парсинг надійний. Crawlee вирішить проблеми, яких у нас **поки немає** (блокування IP, падіння черги).

### ✅ Повернутися до цього, коли:

1. tips.gg почне actively блокувати наш скрапер (Cloudflare / 403)
2. З'явиться третє джерело для скрапінгу
3. Скрапер почне падати частіше ніж раз на день
4. Буде потрібен скрапінг з декількох джерел одночасно

### 🟡 Що можна взяти з Crawlee **без міграції**

1. **`puppeteer-extra` + `puppeteer-extra-plugin-stealth`** — легкий anti-detection для поточного Puppeteer (див. `#4 berstend/puppeteer-extra`)
2. **`browserless`** — окремий Docker-контейнер з Chromium, який не крашить (див. `#5 browserless/browserless`)
3. **Fingerprint randomization** — додати `puppeteer-extra-plugin-stealth` до поточного `puppeteer.launch()`

```ts
// Мінімальне покращення без міграції:
import puppeteer from "puppeteer-extra";
import StealthPlugin from "puppeteer-extra-plugin-stealth";

puppeteer.use(StealthPlugin());
// Далі — той самий код
```

Це дасть ~80% анти-детекту Crawlee, змінивши 3 рядки.
